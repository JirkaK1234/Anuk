# Anuk Discord-like komunity

- Odstraněn starý blok `#anukCommunitiesMaster`, demo ukázková data a reset tlačítko.
- Komunitní modul běží jen na `feed.html` uvnitř `#anukCommunitiesEntry` / `#anukCommunityShell`.
- Roomky fungují jako Discord-like prostor: servery, kanály, chat, live/hlas, členové a nastavení.
- Skupinky mají nástěnku, diskuze, pravidla, členy, žádosti a moderaci.
- Fanpage mají příspěvky, informace, sledující, statistiky a správu stránky.
- Vlastník může upravit logo, cover, název, slogan, popis, pravidla, připnutý text, soukromí, práva, live a zobrazení.
- Komentáře a chat používají normální input bary, žádné browser prompt okno pro komentáře.
- Oprava hovoru nad chatem zůstává zachovaná.

Poznámka: ukládání je lokálně přes `localStorage`, připravené na pozdější napojení backendu.
